## How results are produced (run from the project folder)
- Episodes: experiments/run_v3.py, run_safeopt_ref.py, regen_domain.py (domains: scm, lending, ihdp)
- Summaries and tables: analyze_v3.py <domain>  ->  figures_v3.py  ->  make_tables_v3.py
- IHDP extra ablations: run_ablation2.py -> swap_ihdp_ablation.py; post-hoc table: make_posthoc_betacell.py
- MIMIC: mimic_audit.py -> make_mimic_tables.py (patient-level data never leaves this machine)
